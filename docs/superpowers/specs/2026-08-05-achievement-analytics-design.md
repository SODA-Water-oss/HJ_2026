# 个人收支成就分析设计

日期：2026-08-05

## 目标

在分析页增加「成就总览」，让用户从「记账」中获得及时、持续的个人成就感：通过财务健康分、冲刺目标、连续达标和徽章，把收支数据转化为正向反馈。

## 设计原则

- 成就区不跟随账本筛选条件，始终基于全部记录和当前默认币种计算，保证数字稳定。
- 统计类数据（总览、图表、分类占比、健康分）始终以账本记录为准，增删改后实时重算。
- 徽章和 streak 采用实时审核：数据变更后立即重新评估，合规则颁发/保留，不合规则撤销，再合规则再颁发。
- 界面始终显示最新持有状态和最新颁发时间；补录历史数据合规时可按当前时间补发徽章。
- 所有新界面必须复用 App 现有设计体系：`AppTheme` 色板、现有字号、卡片圆角阴影、Sheet 与分段切换交互，不引入新的视觉语言。

## 范围

本次只做分析页成就系统和本地数据支撑，不涉及账本、账单、设置模块的既有功能。云同步不在本次范围，但数据结构和接口预留。

## 成就总览结构

成就总览位于分析页顶部（「收支综合」之前），采用已确认的 A 布局：

1. 大健康分卡：总分、等级文字，可展开五维明细条。
2. 双列卡片：
   - 左侧「冲刺目标」：名称、金额进度、截止日期、预计完成时间。
   - 右侧「连续达标」：当前周 streak、最近若干周达标小方块。
3. 徽章抽屉：显示已持有徽章，点开可见颁发时间；被撤销的徽章灰显并标注「当前未持有」。
4. 本周小结：本周预算、本周支出、达标状态、距离结算还剩几天。
5. 页面底部「评分规则」说明卡：展示五维健康分、日/周达标、徽章条件。

空状态：

- 无记录：成就区显示轻量空态，不显示 0 分卡。
- 无目标：引导「设第一个目标」。
- 无预算：自动使用近 90 天平均支出作为参考预算，提示用户可手动设置。

## 数据模型

`AchievementModels.swift` 包含：

- `FinancialGoal`：名称、目标金额、已有积蓄、截止日期、是否当前冲刺目标、排序、创建时间。
- `BudgetSetting`：手动月预算（可选）、参考预算来源标记。
- `PeriodSummary`：按周/月聚合的收入、支出、储蓄率、是否达标、最大单笔支出、记录数、更新时间。
- `BadgeDefinition`：徽章标识、类型、门槛值、名称、等级。
- `BadgeAwardEvent`：徽章标识、目标周期、事件类型（颁发/撤销）、发生时间。
- `AchievementSnapshot`：健康分、五维明细、当前 streak、当前目标进度、持有徽章、本周小结。

## 架构与组件

- `AchievementEngine`：纯计算单元。负责周期汇总、达标判定、五维健康分、streak 重算、徽章审核。不依赖 UI。
- `AchievementManager`：`@MainActor ObservableObject`。订阅 `SupabaseService.allRecords`，调用 Engine 生成快照，负责本地持久化和预留云同步接口。
- `AnalyticsAchievementView`：成就总览区块。
- `GoalManagementSheet`：分析页内的目标管理 Sheet，支持新增、编辑、删除、设置冲刺目标、设置月度预算。

## 数据流

1. 账本数据变更（新增、编辑、删除、补录）触发 `allRecords` 发布。
2. `AchievementManager.reconcile()` 只更新受影响周期的 `PeriodSummary`。
3. 重算健康分、周 streak、徽章审核。
4. 持久化本地状态。
5. 发布 `AchievementSnapshot`，成就区只读快照渲染。

目标或预算变更直接更新本地模型，然后重算目标进度和健康分并持久化。

耗时计算放后台，通过请求版本号防止旧结果覆盖新结果；界面不阻塞主线程。

## 健康分与达标规则

### 预算口径

- 用户手动设置月度预算优先。
- 未设置时，参考月预算 = 近 90 天平均支出。
- 周预算 = 月预算 ÷ 4.33。
- 今日预算 = 月预算 ÷ 当月天数。

### 五维健康分（各 20 分，总分 100）

- 储蓄率：当月 `(收入 - 支出) / 收入`。≥30% 得 20 分，≥20% 得 16 分，≥10% 得 12 分，≥0% 得 8 分，负储蓄得 0 分。
- 预算控制：本月支出 ≤ 预算得满分，超支按超出比例扣分。
- 支出稳定性：最近 90 天周支出的标准差 / 均值，越稳定分越高。
- 结余趋势：最近 3 个月净结余是否为正、是否在改善，按趋势打分。
- 大额支出占比：本月最大单笔支出 / 本月总支出，占比越低分越高。

### 日 / 周 / 月

- 日健康：今天有记录时，今日支出 ≤ 今日预算且今天有结余，记为「今日健康」。
- 周达标：周支出 ≤ 周预算，记为达标周。
- 月度徽章结算：自然月结束后，当月至少 3 周达标记为一个达标月。

### streak 与徽章

- 周 streak：连续达标周数，实时审核，数据变更后立即重算。
- 周里程碑徽章：连续 1 / 4 / 8 / 12 / 26 / 52 周解锁。
- 月度徽章：累计 3 / 6 / 12 / 24 个达标月，分别获得铜、银、金、钻徽章。
- 徽章为持续审核状态：合规颁发、不合规撤销、再合规再颁发。
- 每个徽章记录最新颁发时间；界面始终显示当前持有状态和最新颁发时间。
- 补录历史数据后，只要目标周期合规，可按当前时间补发徽章。

## 目标与冲刺

- 支持多个目标，一次只追一个「冲刺目标」。
- 目标字段：名称、目标金额、已有积蓄、截止日期。
- 当月结余全部计入当前冲刺目标。
- 目标达标后弹庆祝，并询问是否切换到下一个目标，确认后切换。
- 预计完成时间根据当前冲刺进度和近 90 天平均月结余估算。

## 持久化与错误处理

- 目标、预算、周期汇总、徽章事件、streak 状态统一以 JSON 存入 `UserDefaults`，模型带 `schemaVersion`。
- 预留 `saveToCloud()` / `loadFromCloud()` 接口，后续接 Supabase。
- JSON 解析失败时不崩溃，回退空成就状态并记日志；保留最近一次成功快照。
- `AchievementManager` 主线程串行处理变更，耗时计算后台执行。
- 边界情况：跨周/跨月、补录多年数据、删除后周期为空、默认币种切换，均走同一套周期汇总重算。

## 性能

- 按周期聚合 + 增量更新：新增、修改、删除只更新对应周期的汇总。
- streak 审核只扫描周期达标标记，不随账单总数增长。
- 健康分基于周期汇总计算，计算量很小。
- 大量数据时后台计算 + 快照渲染，不阻塞 UI。

## 测试范围

- 周期汇总：按周/月正确聚合；增删改只影响对应周期；补录多年数据能触发目标周期重算。
- 达标判定：日健康双条件、周预算达标、月度至少 3 周达标的边界。
- streak：实时重算、断掉归零、补录历史导致变长或变短。
- 徽章：里程碑颁发、不达标自动撤销、再合规再颁发、补录补发、最新颁发时间更新。
- 健康分：五维阈值、空数据、无收入、超预算、默认币种切换。
- 目标：冲刺进度、达标后推荐切换、截止日期与预计完成时间。
- 持久化：JSON 损坏回退、schemaVersion 迁移、重启后恢复。
- 界面：构建通过、空状态、规则说明卡。
