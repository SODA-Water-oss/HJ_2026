# 分析页综合统计重构设计

日期：2026-07-31

## 目标

让分析页「综合统计」全面反映用户资金使用情况：钱从哪来、花到哪去、净结余多少、趋势怎么走、每日资金节奏如何、资金健康度怎样，并保证多币种记账下口径统一、不混币计算。

## 范围

本次只改分析页（`AnalyticsView.swift`）及新增图表组件，不涉及账本、账单、设置等模块。

## 综合统计结构

「收支综合」分区自上而下为：

1. 币种切换 + 总览卡片（收入、支出、净结余、笔数）
2. 月度收支柱状图
3. 月度净收入折线图
4. 当月每日收支点状图
5. 资金健康指标（支出环比、储蓄率、日均支出、大额支出占比）

「支出」「收入」分区保留现有饼图 + 类别明细，并补充币种标识。

## 币种口径

- 币种切换控件放在「收支综合」标题右侧，只列出当前筛选数据中出现过的币种，默认选中默认币种（`currency_symbol`），若默认币种不在数据中则选第一个。
- 总览卡片、三张图、健康指标全部只统计选中币种记录。
- 选中币种在当前筛选范围内无记录时，各卡片显示轻量空态文案。
- 类别区仍按 `类别 + 币种` 分组，图例和明细中显示币种符号。

## 图表规格

使用系统 Swift Charts（iOS 17 原生），统一按 `AppTheme` 定制：

- 柱状图：按月收入 / 支出分组对比；收入绿色、支出紫蓝，圆角柱体。
- 折线图：按月净收入趋势；带数据点，正负颜色区分，纵轴自动适配。
- 点状图：当月每日收支金额分布；X 轴日期、Y 轴金额，收入绿点、支出紫蓝点。
- 图表容器用固定 aspect-ratio 自适应宽度，刻度 11-12、图例 13，全部使用 `AppTheme` 色板和现有字号体系。
- 原有自定义趋势横条卡（`trendCard`）由新三图替换。

## 文字层级

- 总览卡片主数字：收入 / 支出 / 净结余用 28-32 semibold，币种符号略小。
- 卡片标题：17 semibold。
- 图表内刻度：11-12，弱化颜色。
- 图例：13。
- 健康指标数值突出（17 medium+），标签弱化（appBody secondary）。
- 小屏用 `minimumScaleFactor` 防止溢出，不缩放整个页面字体。

## 数据计算

- `analyticsRecords = filteredRecords.filter { $0.displayCurrency == 选中币种 }`
- 月度柱状 / 折线数据按 `month` 分组。
- 每日点状数据按选中月份每一天聚合收入 / 支出合计，一天两个点（收入、支出）。
- 健康指标只基于选中币种记录；支出环比的上月取选中月份前一个月。
- 大额支出占比 = 当月最大单笔支出 / 当月总支出。

## 实现位置

- 新增 `Views/AnalyticsCharts.swift`：币种切换、柱状图、折线图、点状图及图表数据模型。
- `AnalyticsView.swift`：接入综合统计结构，修正总览、健康指标聚合，替换 `trendCard`。
- 不需要修改 Xcode 工程文件；`import Charts` 在 iOS 17 target 下可直接使用。

## 验证

- `xcodebuild build` 通过。
- 检查单币种、多币种、无选中币种数据三种情况下的显示。
- 保留现有「支出」「收入」分类结构，不删减原有功能。
