# 花计2046 — 从零到提交 App Store 操作顺序（一页纸）

> 按顺序执行，每步完成后打勾。预计总耗时 3–7 天（主要等开发者账号审核和 App 审核）。

---

## 第 1 步：注册 Apple 开发者账号（¥688/年）

- [ ] 访问 https://developer.apple.com/programs/enroll 注册（个人开发者即可）
- [ ] 准备：Apple ID、身份证、Visa/Mastercard 银行卡
- [ ] 付款后等审核（个人通常几分钟~24 小时）

## 第 2 步：配置本地密钥

- [ ] 复制模板：
  ```bash
  cd /Volumes/MyData/【01工作资料】/【MyWork】/MyAPP/001_HJ/花计2046
  cp Configs/Local.xcconfig.example Configs/Local.xcconfig
  ```
- [ ] 在 Supabase / DeepSeek 后台**轮换旧密钥**（旧 key 曾进过 Git 历史）
- [ ] 编辑 `Configs/Local.xcconfig` 填入新密钥

## 第 3 步：准备后端

- [ ] 创建 Supabase 项目
- [ ] SQL Editor 按顺序执行迁移：001 → 002 → 003 → 004 → 005 → 006 → 008 → 009 → 011 → 012 → 013 → 014 → 015
- [ ] 部署 Edge Functions：
  ```bash
  supabase functions deploy parse-expense
  supabase functions deploy delete-account
  supabase functions deploy spending-review
  ```
- [ ] 配置函数环境变量：`SUPABASE_URL`、`SUPABASE_SERVICE_ROLE_KEY`、`GEMINI_API_KEY`、`DEEPSEEK_API_KEY`
- [ ] Authentication → URL Configuration → Redirect URLs 添加：`huaji2046://reset-password`

## 第 4 步：App Store Connect 建 App

- [ ] 登录 https://appstoreconnect.apple.com
- [ ] App → + → 新建 App
  - 名称：花计2046
  - 主语言：简体中文
  - Bundle ID：`com.nsoft.huaji2046`
  - SKU：`huaji2046`
- [ ] 定价选择免费，不配置 IAP/订阅
- [ ] 创建审核演示账号（在 Supabase 后台注册），准备几条演示数据

## 第 5 步：部署隐私政策

- [ ] 将 `花计2046/Legal/PrivacyPolicy.html` 内容部署到网站
- [ ] 记下 URL（如 https://your-domain.com/privacy），后续填入 App Store Connect

## 第 6 步：Xcode 构建验证

- [ ] 打开 `花计2046.xcodeproj`，确认 Configurations 已关联 Configs/ 下的 xcconfig
- [ ] 选择 iPhone 真机或模拟器，⌘R 运行，回归测试核心流程：
  - 注册/登录 → 记账 → AI 解析 → 分析 → 退出登录 → 忘记密码
- [ ] 运行单元测试：
  ```bash
  xcodebuild test -project 花计2046.xcodeproj -scheme 花计2046 \
    -destination "platform=iOS Simulator,name=iPhone 17 Pro"
  ```
- [ ] 清理 `.bak` 备份文件（含旧密钥）

## 第 7 步：提交代码到 Git

- [ ] `git status` 确认 `Local.xcconfig` 未进暂存区
- [ ] `git add` 所有改动 + `git commit -m "feat: 完成上架前改造"`
- [ ] `git push`

## 第 8 步：提交审核

- [ ] Xcode：Product → Archive（Release 配置）
- [ ] Organizer → Distribute App → App Store Connect
- [ ] 在 App Store Connect 填写：
  - 描述、关键词、副标题（见《App Store 审核材料清单》）
  - 隐私政策 URL
  - 截图（6 张 iPhone 6.7"）
  - 审核备注（演示账号 + 说明）
- [ ] 提交审核 → 等 24–48 小时

## 第 9 步：上线后

- [ ] 处理审核反馈（如有）
- [ ] 发布版本
- [ ] 监控崩溃（Xcode Organizer / 第三方）

## 注意事项

1. **开发者账号必须先注册**，否则第 3、4 步的 Supabase 和 App Store Connect 配置无法与 Apple 关联。
2. **旧密钥必须轮换**，泄露的 key 会被滥用。
3. **Release 构建**与 Debug 不同（AI 解析走后端、无 DeepSeek key），务必用 Release archive 测试一次。
4. **首次上架建议用 TestFlight** 先给少量真实设备测试再正式提交。
